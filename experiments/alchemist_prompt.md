# AlCHEmist 提示词：生成 SCAYS 标注函数

以下提示词用于让 LLM 生成 10 条标注规则函数。每次调用时修改 `策略提示` 部分，得到不同视角的规则。

---

## 通用提示词模板

```
你是一个 Python 编程专家。请为以下任务写一个可执行的标注函数。

【任务描述】
判断一条中文青少年社交媒体帖子（来自小红书）是否包含情绪表达。
数据来源是中国初高中学生的社交媒体发言，涵盖学业压力、家庭关系、校园生活、同伴关系等场景。

【标注指令】
- 返回 1 = 有情绪（正面或负面情绪表达）
- 返回 0 = 中性（无明显情绪、纯叙事、问答、通知）
- 返回 -1 = 不确定（弃权，不投票）

【重要背景知识】
- 中国青少年常用特殊表达：
  "吃谷" = 花钱买动漫周边
  "塌房" = 喜欢的偶像/角色翻车
  "小镇做题家" = 来自小城市靠刷题考学的学生
  "百日誓师" = 高考前100天的动员大会
  "开学综合征" = 开学前后的焦虑状态
-隐含情绪很常见：句子可能没有情绪词，但情境暗示了情绪
  例："月考成绩发下来了" → 无情绪词，但暗含焦虑

【数据示例】
有情绪(1)的例子：
- "玛雅，我简直觉得是我妈给我发的，说我没用，我该怎么办"
- "有周测又有月考的真的炸了每天都在考在焦虑"
- "写得真好，我很坚定，因为我不想宝宝有一个不爱他的爸爸"

中性(0)的例子：
- "可靠消息今年九点就能查分"
- "笑死我了 那你删掉最后一句也能用"
- "我只知道台湾的新闻标题都挺三俗的"

【函数签名】
def label_emotion(sentence: str) -> int:

【策略提示】
{见下方10条不同策略}

请只返回一个完整的 Python 函数，不要解释。函数必须可以直接运行。
```

---

## 10 条不同的策略提示（每次替换上面的 {策略提示}）

### 策略 1：情绪关键词
```
请基于情绪关键词来判断。如果句子中包含明确的情绪词（如焦虑、崩溃、开心、难过、害怕、烦、累等），返回1。如果没有任何情绪信号，返回0。不确定时返回-1。
```

### 策略 2：否定表达
```
请关注否定式表达。如果句子包含"不想""没有""受不了""忍不了""撑不住"等否定+消极组合，返回1。纯否定但不含情绪的返回0。不确定返回-1。
```

### 策略 3：求助/无助句式
```
请关注求助和无助的句式。如果句子包含"怎么办""咋办""该怎样""救命""谁能帮帮我"等表达，返回1。普通问句返回0。不确定返回-1。
```

### 策略 4：程度副词+评价
```
请关注程度副词和评价词的组合。如"真的好累""太难了""超级烦""好害怕"等强烈程度表达，返回1。程度副词修饰中性内容（如"真的很高"指身高）返回0。不确定返回-1。
```

### 策略 5：身体/生理信号
```
请关注身体和生理状态描述中暗含的情绪。如"失眠""哭了""胃疼""头疼""吐了""心跳加速"等，这些通常暗示情绪压力，返回1。纯粹描述身体事实无情绪色彩返回0。不确定返回-1。
```

### 策略 6：学业压力场景
```
请关注学业压力场景的组合。如果句子同时提到考试/成绩相关词（月考、一模、成绩、分数）AND 负面结果词（完了、炸了、凉了、挂了、来不及），返回1。只提到考试无情绪倾向返回0。不确定返回-1。
```

### 策略 7：人际关系冲突
```
请关注人际关系中的冲突信号。如果句子涉及被骂、被打、吵架、孤立、冷暴力、没朋友等人际伤害，返回1。正常描述人际关系（如"我和同桌一起吃饭"）返回0。不确定返回-1。
```

### 策略 8：家庭相关情绪
```
请关注家庭场景中的情绪信号。如果句子涉及父母吵架、被骂、不理解、重男轻女、离婚、家暴等，返回1。正常描述家庭生活返回0。不确定返回-1。
```

### 策略 9：自我否定/自卑
```
请关注自我否定和自卑表达。如果句子包含"我太差了""我什么都不行""废物""没用""不配"等自我贬低，返回1。客观自我描述（如"我是理科生"）返回0。不确定返回-1。
```

### 策略 10：正面情绪
```
请关注正面情绪表达。如果句子包含开心、期待、感动、感恩、骄傲、满足、终于成功等积极情绪，返回1。中性叙事返回0。不确定返回-1。
```

---

## 使用方法

1. 将上述模板分10次发给 LLM（如GPT-4 / Claude / DeepSeek），每次换一个策略提示
2. 收集10个Python 函数
3. 对每条数据跑10个函数，得到10个投票
4. 用多数投票或加权聚合（Snorkel）得到最终标签
5. 对比最终标签和你原有的 LLM 标签，计算一致率
